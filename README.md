# План на 6 месяцев — трекер

Интерактивный трекер плана на 16.11.2026 – 16.05.2027 по теории 6 месяцев.

**Открыть:** https://a-revazyan.github.io/plan-6-months/

## Что внутри

- **Сегодня** — чеклист дня (утро, день, вечер) по шаблону недели, приёмы пищи, 3 задачи, энергия, заметка. Режим «плохой день — только минимум».
- **Неделя** — дни недели по цвету, план/факт (рилсы, силовые, сон, еда), воскресный замер (подписчики, вес, мышцы) против плана, разбор недели.
- **Месяц** — задачи этапа, контрольная точка план/факт, итоги по дням, награда.
- **Цели** — прогресс от точки А к точке Б, графики, все 182 дня, список 15 проектов со статусами.
- **Ещё** — цели и режим, синхронизация, резервная копия.

## Где хранятся данные

В браузере на устройстве (localStorage). В репозиторий ничего не попадает.
Чтобы заполнять трекер и с телефона, и с компьютера, включи синхронизацию во вкладке «Ещё».
Данные будут лежать в твоём **секретном** gist на GitHub. Для этого нужен токен с правом `gist`.

## На телефон как приложение

iPhone: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
Android: Chrome → меню → «Добавить на главный экран».
